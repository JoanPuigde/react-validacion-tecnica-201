# J03-02 — HOC

[← Página anterior](J03-01-contexto.md) · [Siguiente página →](J03-03-memo.md)

> Laboratorio de [HOC](README.md).

### Objetivo

Sacar `useSesion` de `Tarjeta`. Una función recibe el componente y le pasa `revisor` como prop.

### Código de partida

[J03-01](J03-01-contexto.md) está hecho: `SesionProveedor` envuelve `<App />` en `main.tsx`, y `Tarjeta` llama a `useSesion()`. Si no, ese laboratorio trae los archivos.

### 1 — La función que envuelve

**Dónde:** archivo nuevo `bandeja/src/hoc/conRevisor.tsx`, y `Tarjeta.tsx`.

**Qué haces:**

1. Crea el archivo del HOC y pega esto.
2. En `Tarjeta`, `revisor` pasa a ser prop. Quita `useSesion` de la ficha.
3. La última línea del archivo deja de exportar la función a pelo.
4. Guarda. Escribe `Luis` en la caja.

```tsx
import type { ComponentType } from "react"
import { useSesion } from "../contexto/Sesion"

export function conRevisor<P extends { revisor: string }>(
  Componente: ComponentType<P>,
) {
  function Envuelto(props: Omit<P, "revisor">) {
    const { revisor } = useSesion()
    const completas = { ...props, revisor } as P
    return <Componente {...completas} />
  }
  return Envuelto
}
```

En `Tarjeta.tsx`, el import de `useSesion` se sustituye por este:

```tsx
import { conRevisor } from "../hoc/conRevisor"
```

La interfaz y la función quedan así. El `return` de la ficha no se toca: sigue pintando `{revisor}`.

```tsx
interface TarjetaProps {
  item: Entregable
  textoBoton?: string
  alMarcar: (id: string) => void
  revisor: string
}

function Tarjeta({
  item,
  textoBoton = "Anotar",
  alMarcar,
  revisor,
}: TarjetaProps) {
```

Y el archivo termina así, sin `export default function`:

```tsx
export default conRevisor(Tarjeta)
```

En `App`, la etiqueta sigue siendo `<Tarjeta item={item} alMarcar={marcar} />`. No le pases `revisor`.

**Experimento:** cambia la última línea a `export default Tarjeta`. Lee Problems. Vuelve a `export default conRevisor(Tarjeta)`.

→ Con el HOC, las seis fichas siguen en «Revisor: Ana» y `Luis` las cambia todas. `App` no escribe `revisor=`. Sin el HOC, Problems pide esa prop en cada `<Tarjeta>`.

**Validación:**

- `useSesion` está en `conRevisor.tsx`, no en `Tarjeta.tsx`.
- Problems vacío con `export default conRevisor(Tarjeta)`.
- El filtro sigue respondiendo.

## Comprueba tu entendimiento

**Qué devuelve un HOC**
`conRevisor` no pinta la ficha. Devuelve `Envuelto`.
→ `Envuelto` lee el contexto y llama a `Tarjeta` con la prop ya puesta. `memo`, en el laboratorio siguiente, es un HOC que ya trae React: también recibe un componente y devuelve otro.

## Reto

### 1 — Llamarlo como componente

En `App`, cambia `<Tarjeta item={item} alMarcar={marcar} />` por `<conRevisor />`.
→ Problems. Un HOC se llama como función, con el componente dentro: `conRevisor(Tarjeta)`. Restaura la etiqueta `<Tarjeta>`.

## Errores frecuentes

| Síntoma | Causa probable | Cómo arreglarlo |
|---------|----------------|-----------------|
| Falta `revisor` en `<Tarjeta>` | Exportaste `Tarjeta` sin envolverla | `export default conRevisor(Tarjeta)` |
| `useSesion fuera del proveedor` | `Envuelto` quedó fuera de `SesionProveedor` | El proveedor sigue envolviendo `<App />` en `main.tsx` |
| El nombre no cambia | La ficha pinta un texto fijo | El párrafo sigue siendo `Revisor: {revisor}` |
