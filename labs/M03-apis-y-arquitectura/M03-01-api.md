# M03-01 — La petición

[← Página anterior](README.md) · [Siguiente página →](M03-02-estructura.md)

> Práctica del módulo. La teoría y la demo están en el [README del módulo](README.md).

### Objetivo

Cargar los entregables desde `/entregables.json` y distinguir carga, error y lista vacía.

### Prerrequisitos

- [M02-02](../M02-estado-y-hooks/M02-02-efectos.md): filtro, `marcar` y título de pestaña en `App.jsx`.

### En qué consiste

Sustituyes el array importado por un `fetch` en un efecto. Conservas filtro, marca y título.

### 1 — Pedir el JSON al montar

**Acción:** en la función `Bandeja` de `src/App.jsx`, quita el import de `datos.js` si ya no se usa. El estado inicial de la lista pasa a ser un array vacío. Añade `cargando` y `error`, y este efecto **además** del efecto del título. No juntes los dos en uno. Los hooks se quedan dentro de `Bandeja`, no en `App`.

```jsx
const [items, setItems] = useState([])
const [texto, setTexto] = useState("")
const [cargando, setCargando] = useState(true)
const [error, setError] = useState("")

useEffect(() => {
  let vivo = true
  async function cargar() {
    try {
      const respuesta = await fetch("/entregables.json")
      if (!respuesta.ok) throw new Error(String(respuesta.status))
      const datos = await respuesta.json()
      if (vivo) setItems(datos)
    } catch {
      if (vivo) setError("No se pudo cargar la bandeja.")
    } finally {
      if (vivo) setCargando(false)
    }
  }
  cargar()
  return () => {
    vivo = false
  }
}, [])
```

En el JSX, antes de la lista:

```jsx
{cargando ? <p>Cargando entregables…</p> : null}
{error ? <p role="alert">{error}</p> : null}
{!cargando && !error && visibles.length === 0 ? (
  <p>Ningún entregable coincide.</p>
) : null}
```

Quita el párrafo de vacío que ya tenías suelto, para no duplicarlo. La lista solo se pinta si no hay carga ni error:

```jsx
{!cargando && !error ? (
  <ul className="lista">
    {visibles.map((item) => (
      <li key={item.id}>
        <Tarjeta item={item} alMarcar={marcar} />
      </li>
    ))}
  </ul>
) : null}
```

`pendientes`, `marcar` y el efecto del `document.title` se quedan como estaban.

**Por qué:** el primer pintado ocurre con `cargando` a verdadero. La respuesta llega después. `vivo` impide actualizar estado si el efecto se limpió.

**Resultado esperado:** al recargar, las fichas aparecen y el título de la pestaña dice «Pendientes: 3». La caja «Buscar» sigue filtrando. `src/datos.js` ya no se importa desde `App.jsx`.

### 2 — Provocar el error y volver

**Acción:** cambia la URL a `fetch("/entregables-mal.json")`, guarda, recarga la página. Lee el aviso. Devuelve `fetch("/entregables.json")`, guarda y recarga.

**Por qué:** un 404 no lanza solo. Hay que mirar `respuesta.ok` y lanzar para caer en el `catch`. Sin eso, un JSON de error o una página vacía acabarían en `setItems`.

**Resultado esperado:** con la URL mala se lee «No se pudo cargar la bandeja.» y no hay fichas. Con la URL buena vuelven las seis.

> [!WARNING]
> Si el `catch` hace `setItems([])` y no `setError`, la pantalla de error y la de vacío se confunden. El aviso tiene que depender de `error`.

## Comprueba tu entendimiento

**Vacío no es error**

## Reto

### 1 — Hacer visible la carga

La respuesta local es tan rápida que «Cargando entregables…» casi no se ve. Retrasa la asignación dos tercios de segundo y comprueba el texto. Quita el retraso al terminar.

<details>
<summary>Ver solución</summary>

Justo antes de `setItems(datos)`:

```jsx
await new Promise((resolver) => setTimeout(resolver, 700))
```

Al recargar se lee «Cargando entregables…» y después las fichas. Borra esa línea para no dejar un retardo artificial en la bandeja.

</details>

## Errores frecuentes

| Síntoma | Causa probable | Cómo arreglarlo |
|---------|----------------|-----------------|
| Las fichas no vuelven y no hay error | `setCargando(false)` no está en `finally` y una rama se olvida | El `finally` pone `cargando` a falso siempre que `vivo` siga en true |
| Bucle de peticiones en la pestaña Network | El efecto depende de `items` o no tiene `[]` | El efecto de carga lleva `[]` |
| `pendientes` explota | `items` no es un array (se guardó el objeto respuesta entero) | `setItems` recibe el resultado de `respuesta.json()`, que es el array |
