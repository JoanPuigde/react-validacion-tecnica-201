# React para validación técnica, testing y rendimiento

[Siguiente página →](labs/M01-tsx-y-componente/README.md)

React con TypeScript, de concepto en concepto, sobre la [bandeja de entregables](bandeja/README.md). Cada laboratorio añade una sola cosa, la usa y comprueba el resultado antes de seguir.

El entorno es el dev container del repositorio. En GitHub: **Code → Create codespace on main**. Dentro de `bandeja/`, `npm run dev` abre el puerto **5173**.

## Cómo se sigue

Una sola carpeta, `bandeja/`. No abras otro proyecto. El orden es el de la tabla: al terminar un laboratorio, el enlace **Siguiente** es el próximo concepto.

Componentes funcionales, ficheros `.tsx`, interfaces propias. Sin `any` y sin clases.
