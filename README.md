# React para validación técnica, testing y rendimiento

[Siguiente página →](labs/M01-fundamentos/README.md)

Formación práctica. Una sola aplicación, la [bandeja de entregables](bandeja/README.md), se lee, se completa, se mide y se valida.

El entorno es el dev container del repositorio. En GitHub: **Code → Create codespace on main**. Al terminar de preparar el contenedor, el puerto **5173** queda listo para `npm run dev` dentro de `bandeja/`.

## Cómo funciona el curso

Sigue este README como índice y avanza **página a página** con **← Página anterior · Siguiente página →**.

Cada módulo tiene dos niveles: el **README del módulo** con la **teoría** y la **demostración**, y uno o varios **laboratorios** donde practicas tú.
